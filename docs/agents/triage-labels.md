# Triage Labels

The repository uses the 5 canonical triage roles:

- `needs-triage`: Newly submitted issue or ticket requiring initial triage.
- `needs-info`: Blocked on additional information or clarification from the reporter.
- `ready-for-agent`: Fully specified task ready for autonomous agent execution.
- `ready-for-human`: Task requires human intervention, physical hardware access, or approval.
- `wontfix`: Out of scope or decided against.
