# Issue Tracker: GitHub Issues

Issues for Borneo Jasa POS are tracked using GitHub Issues in the `Tofui03/BJ-POS` repository.

## Commands

- **List open issues**:
  ```bash
  gh issue list
  ```
- **View issue**:
  ```bash
  gh issue view <number>
  ```
- **Create issue**:
  ```bash
  gh issue create --title "<title>" --body "<body>"
  ```
- **Close issue**:
  ```bash
  gh issue close <number>
  ```
